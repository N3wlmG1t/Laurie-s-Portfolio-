Complex Procedure

This two-part procedure explains a prompt-based tool that builds simple programming commands, which modify large data files before importing them. I worked closely with the development team to learn and test the tool while writing the instructions.

Part one walks through building an Add Fields rule set; part two covers building a Change Fields rule set, including how to use Conditions to restrict which records a rule affects. Each step is written to match exactly what the user sees in the tool, in the order they'll encounter it.
